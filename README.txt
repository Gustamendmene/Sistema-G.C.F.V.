PROJETO 2026 - MERCADINHO SÃO JOSÉ
Sistema de Controle de Estoque e Validade

COMO EXECUTAR NO WINDOWS:
1. Extraia a pasta projeto 2026 em Documentos ou outro local.
2. Abra o VS Code e escolha File > Open Folder.
3. Selecione a pasta mercadinho_sao_jose.
4. Abra Terminal > New Terminal.
5. Crie o ambiente virtual: python -m venv .venv
6. Ative: .\.venv\Scripts\Activate.ps1
7. Instale: python -m pip install -r requirements.txt
8. instalar: mysql-connector-python
9. python-dotenv
10.Execute: python main.py

A logo enviada está em assets/logo_sao_jose.png.
